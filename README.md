# Matrix Rain Portfolio Template  
_A responsive, dark-themed hacker-style portfolio website built with React, Tailwind CSS, and GSAP animations._

![Preview Screenshot](preview.png)  
[**Live Demo →**](https://your-demo-link.com)

---

## 🚀 Features
- **Matrix-Style Background Animation** – immersive code rain effect
- **Glitch Text Hero Section** – eye-catching animated heading
- **Fully Responsive** – works on mobile, tablet, and desktop
- **Smooth Scroll Animations** – powered by GSAP
- **Modern Tech Stack** – React + Tailwind CSS
- **Easy Customization** – well-commented code and simple file structure

## 🛠️ Installation & Setup
1. **Clone or download** this repository:
   ```bash
   git clone https://github.com/MellonP/Hacker-Portfolio.git
   cd hacker-portfolio
````

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Run development server**:

   ```bash
   npm run dev
   ```

4. **Build for production**:

   ```bash
   npm run build
   ```

---

## 🎨 Customization

* **Colors:** Edit `tailwind.config.js` to change the color palette
* **Text & Content:** Modify the files in `/src/components`
* **Animations:** GSAP settings are in `animations.js`
